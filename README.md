# بوت تسجيل أيام الشغل (Gig Tracker) - النسخة المطوّرة
**Made by OmarMidlg**

بوت تيليجرام لتسجيل أيام الشغل مع محمد زيدان (أو أي حد بتشتغل معه)، وكل مستخدم إله حساب خاص فيه.

## المزايا الجديدة بهاي النسخة
- ✏️ **تعديل أي يومية** بعد ما تسجّلها (التاريخ، المكان، الشغل، الشريك، أو المبلغ)
- 🔍 **بحث وفلترة** الأيام حسب التاريخ، المكان، نوع الشغل، أو الشريك
- 📤 **تصدير البيانات** كملف Excel أو PDF (بيدعم العربي بالكامل)
- 📈 **تقرير شهري/سنوي** مع رسم بياني للدخل
- ⏰ **تذكير أسبوعي تلقائي** يبعتلك ملخص حسابك كل أسبوع بيوم وساعة تحددها
- أزرار تفاعلية (Inline Buttons) بدل الكتابة اليدوية لمعظم العمليات

---

## 1. البيانات المسجّلة لكل يومية
- رقم الحدث (Event Number) — يتولّد تلقائياً (1, 2, 3, ...) لكل مستخدم لحاله
- التاريخ
- اليوم — يُحسب تلقائياً من التاريخ
- مكان الحدث
- نوع الشغل
- مين اشتغل معك
- المبلغ (بالشيكل ₪) — الافتراضي 120.00 ₪، وبإضافة كل يومية فيك تكتب رقم آخر أو ترسل `=` لاستخدام الأجرة الافتراضية

## 2. ملخص الحساب
البوت بيحسب تلقائياً:
- الرصيد من الحساب السابق (تقدر تعدّله يدوياً)
- مبلغ الخصم (تقدر تعدّله يدوياً)
- المبلغ المستلم (تقدر تعدّله يدوياً)
- عدد الأيام (الأحداث)
- الصافي من الأيام = مجموع مبالغ كل الأيام المسجّلة
- **الرصيد المتبقي = الرصيد السابق + الصافي من الأيام − الخصم − المبلغ المستلم**

> ملاحظة: هاي هي المعادلة الافتراضية اللي استخدمتها. إذا بدك معادلة مختلفة (مثلاً الخصم يُطرح من المستلم بدل الصافي، أو غير هيك)، قلّي وبعدّلها بسهولة بملف `bot.py` بدالة `build_summary_text`.

كل مستخدم (كل شخص يستخدم البوت) إله حسابه الخاص بالكامل — الأرقام والملخص ما بتختلط بين المستخدمين.

## 3. كيف تشغّل البوت

### أ) اعمل بوت تيليجرام واحصل على Token
1. افتح تيليجرام وابحث عن [@BotFather](https://t.me/BotFather)
2. أرسل `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ bot)
3. رح يعطيك **Token** شكله متل: `123456789:ABCdefGhIJKlmNoPQRstuVwxyZ`
4. احتفظ فيه بمكان آمن — أي حد يعرفه بقدر يتحكم بالبوت

### ب) شغّل البوت على جهازك (تجربة محلية)
يتطلب Python 3.10 أو أحدث.

```bash
cd gig_bot
pip install -r requirements.txt

# على Windows (PowerShell):
$env:BOT_TOKEN="التوكن يلي حصلت عليه"

# على macOS/Linux:
export BOT_TOKEN="التوكن يلي حصلت عليه"

python3 bot.py
```

إذا ظهرت رسالة `Bot starting...` يعني البوت شغّال. افتح تيليجرام، دوّر على اسم البوت متاعك، وابعتله `/start`.

### ج) استضافة دائمة (Deployment) بحيث يضل شغّال 24/7
البوت لازم يضل شغّال على سيرفر حتى يشتغل بشكل دائم. أسهل الخيارات المجانية/الرخيصة:

- **Railway.app** — ارفع الكود كـ GitHub repo، أضف Environment Variable باسم `BOT_TOKEN`، وشغّل الأمر `python bot.py`
- **Render.com** — Background Worker، نفس الفكرة
- **PythonAnywhere** — يدعم Always-On Task (بحاجة اشتراك مدفوع بسيط)
- **VPS خاص فيك** (مثل DigitalOcean) مع `systemd` أو `screen`/`tmux` حتى يضل شغّال بعد إغلاق الطرفية

⚠️ ملف قاعدة البيانات `gig_tracker.db` (SQLite) بينحفظ بنفس مجلد البوت على السيرفر — تأكد إنه المسار قابل للكتابة (writable) على المنصة يلي رح تستخدمها، وخذ نسخة احتياطية منه بين فترة وفترة.

## 4. أوامر واستخدام البوت
بعد `/start` رح تظهر قائمة أزرار:

| الزر | الوظيفة |
|---|---|
| ➕ إضافة يومية | يبدأ سلسلة أسئلة: التاريخ ← المكان ← نوع الشغل ← مين اشتغل معك ← المبلغ |
| 📋 آخر الأيام | يعرض كل الأيام (مقسّمة صفحات)، كل يومية معها أزرار ✏️ تعديل و 🗑️ حذف |
| 📊 ملخص الحساب | يعرض ملخص الحساب الكامل |
| 🔍 بحث | فلترة الأيام حسب التاريخ / المكان / نوع الشغل / الشريك |
| 📤 تصدير البيانات | تنزيل كل بياناتك كملف Excel أو PDF |
| 📈 تقرير شهري/سنوي | رسم بياني يوضح دخلك آخر 6/12 شهر أو حسب كل سنة |
| ⏰ التذكير الأسبوعي | تفعيل/إيقاف إرسال ملخص الحساب تلقائياً كل أسبوع |
| ⚙️ الإعدادات | لتعديل: الرصيد السابق / الخصم / المبلغ المستلم / الأجرة الافتراضية |

أوامر نصية إضافية:
- `/start` — بدء / إعادة عرض القائمة
- `/help` — شرح الأوامر
- `/cancel` — إلغاء أي عملية جارية (مثل إضافة يومية بنص الطريق)

### تعديل يومية
من 📋 آخر الأيام، اضغط ✏️ تعديل بجانب اليومية يلي بدك تغيّرها، اختر الحقل (تاريخ/مكان/شغل/شريك/مبلغ)، وابعت القيمة الجديدة.

### حذف يومية
من 📋 آخر الأيام، اضغط 🗑️ حذف، وأكّد بالضغط على "✅ نعم، احذف".

### البحث
اضغط 🔍 بحث، اختر نوع الفلتر، وابعت القيمة (مثلاً اسم مكان أو تاريخ). النتائج بتظهر بنفس شكل قائمة الأيام مع إمكانية التعديل/الحذف مباشرة، وفيك تمسح الفلتر بزر "❌ مسح البحث".

### التذكير الأسبوعي
اضغط ⏰ التذكير الأسبوعي ← ✅ تفعيل، واختر يوم الأسبوع. البوت رح يبعتلك ملخص حسابك تلقائياً كل أسبوع الساعة 18:00 بذلك اليوم.
⚠️ **مهم جداً:** هاد التذكير بيشتغل بس إذا كان البوت مستضاف على سيرفر ومشغّل بشكل دائم (شوف قسم "استضافة دائمة" فوق). إذا البوت مسكّر (مثلاً شغّال بس على جهازك ومطفّي هلق)، ما رح يوصلك التذكير.

## 5. تعديل الأجرة الافتراضية
عند إضافة يومية جديدة، فيك تبعت `=` لاستخدام الأجرة الافتراضية الحالية مباشرة، أو تكتب أي مبلغ آخر لهاي اليومية بالتحديد بدون ما يتغيّر الإعداد العام. إذا بدك تغيّر الأجرة الافتراضية بشكل دائم لكل الأيام الجايّة، استخدم ⚙️ الإعدادات ← 🏷️ الأجرة الافتراضية لكل حدث.

## 6. بنية الملفات
```
gig_bot/
├── bot.py                          # كود البوت بالكامل
├── requirements.txt                # المكتبات المطلوبة
├── NotoNaskhArabic-Regular.ttf     # خط عربي مستخدم بملفات PDF والرسوم البيانية
└── README.md                       # هاد الملف
```

⚠️ **ملف الخط `NotoNaskhArabic-Regular.ttf` لازم يضل بنفس مجلد `bot.py`** حتى تصدير PDF والتقارير البيانية تشتغل صح وتدعم العربي. إذا نقلت `bot.py` لمجلد تاني، انقل الخط معه.

قاعدة البيانات (`gig_tracker.db`) بتنعمل تلقائياً أول ما تشغّل البوت، بنفس مجلد `bot.py`.

## 7. المكتبات المستخدمة (تُثبّت تلقائياً بـ requirements.txt)
- `python-telegram-bot[job-queue]` — تشغيل البوت والتذكير الأسبوعي
- `openpyxl` — تصدير Excel
- `fpdf2` + `arabic_reshaper` + `python-bidi` — تصدير PDF بدعم عربي كامل
- `matplotlib` — الرسوم البيانية للتقارير الشهرية/السنوية
